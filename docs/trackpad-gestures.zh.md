# 内置四指和五指手势

## 使用前的系统设置

在“系统设置 → 触控板 → 更多手势”中，同时关闭以下两项。

- App（捏拢拇指和其他三指）
- 显示桌面（张开拇指和其他三指）

在已测试的系统中，这两个开关存在联动，需要一起关闭，以免系统动作与 iLaunch 冲突。

## 操作与优先级

四指或五指指总共四个或五个触点，通常为拇指加另外三指或四指。

| 当前状态 | 动作 | 结果 |
| --- | --- | --- |
| 普通应用窗口 | 向内捏合 | 以淡入缩放动画打开 iLaunch |
| iLaunch 正在显示 | 向外张开 | 收起 iLaunch，返回之前的应用 |
| 普通应用窗口 | 向外张开 | 调用系统“显示桌面” |
| 已由手势进入“显示桌面” | 第一次向内捏合 | 恢复原来的窗口 |
| 窗口已恢复 | 再次向内捏合 | 打开 iLaunch |

手势识别直接集成在 iLaunch 内。触点数量为四或五，识别不依赖特定的拇指形状。每轮触摸只触发一次，松开手指后可进行下一轮动作。

## 动画优化

- 启动器打开时淡入并轻微缩放，遵循现有动画与减少动态效果设置。
- 文件夹展开时，主网格背景图标模糊、淡化，文件夹内图标清晰。
- 文件夹开始关闭时，背景同步在 0.16 秒内恢复清晰。
- 收起终点采用实际文件夹图标边界，排除标题和网格留白，并补偿缩放比例。
- 展开时，缩略图淡出跟随实际动画进度，消除大缩略图与展开面板叠加。

## 实现与验证范围

触控数据接口参考 MIT 许可的 [macos-gesture-launcher](https://github.com/okruts/macos-gesture-launcher)，原许可证保存在 Resources/GestureLauncher-LICENSE.txt，并随应用打包。

多指识别使用苹果私有 MultitouchSupport 接口。“显示桌面”使用 CoreDockSendNotification。系统升级可能需要适配。

已在 macOS 27.0.1、Apple Silicon 与外接 Magic Trackpad 上手动验证四指/五指捏合、张开、显示桌面恢复顺序，以及文件夹展开、收起动画。

其他设备、多显示器、Stage Manager、睡眠唤醒、触控板热插拔和手动打开 Finder 窗口后的桌面状态同步仍需补充验证。自动测试目标在当前环境因缺少 TestingMacros 插件而未能编译，独立手势识别断言检查通过。
